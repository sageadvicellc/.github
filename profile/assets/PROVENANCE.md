# Brand artwork sources

The manifest records source hashes and public file URLs for the brand assets. Existing files remain available even when the README no longer uses them.

## Full Sage Advice wordmark

The light and dark SVGs display the approved full wordmark and paired leaves from the round-05 Sage Advice board.

Each SVG embeds the original PNG bytes and uses a viewBox to isolate one composition. Neither file changes lettering, colors, pixels, or leaf shapes.

These are raster-backed display files, not vector masters or transparent logo exports. The manifest records each viewport and the original board hash.

The retained brand-kit review records founder approval of the paired leaves and corrected spacing. The separate vector master remains outside this change.

Public files: [Light wordmark](sage-advice-wordmark-light.svg) and [dark wordmark](sage-advice-wordmark-dark.svg).
