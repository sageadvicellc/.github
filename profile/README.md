### Bowerloom

<picture>
  <source media="(prefers-color-scheme: dark)" srcset="assets/bowerloom-wordmark-cream.svg">
  <img src="assets/bowerloom-wordmark-ink.svg" alt="Bowerloom" width="280">
</picture>

Bowerloom brings governance to agent workflows through portable team definitions and exact approval of supported changes. Roles, skills, handoffs, and proposed permissions stay in files that follow you, outside any one agent application. Your personal agent helps review the team and its working agreement before setup writes the approved files. These definitions propose permissions and grant no runtime authority.

[Explore Bowerloom](https://github.com/sageadvicellc/bowerloom) · [Read the documentation](https://github.com/sageadvicellc/bowerloom#readme)
